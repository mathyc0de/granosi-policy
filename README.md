# granosi-policy

Public legal pages for [Granosi](https://github.com/mathyc0de/granosi).

## Pages

| File | Description |
|------|-------------|
| `index.html` | Landing page with links to policies |
| `privacy.html` | Privacy Policy |
| `terms.html` | Terms of Service |

## Local preview

Open any HTML file in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Assets

- `style.css` — shared styles (dark theme aligned with the app)
- `main.js` — active nav state and auto-generated table of contents on legal pages
